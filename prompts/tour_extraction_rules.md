# 투어 공지 판정 기준

아티스트 공식 X 계정의 포스팅에서 **글로벌 투어·공연 일정 공지**만 골라 구조화한다.
`prompts/classification_rules.md`(음반 구매 연계 이벤트 판정)와는 완전히 별개 기준이다.

## is_relevant = true 조건

아래 **하나 이상**에 해당하면 true.

1. 공연·투어의 **일정, 도시, 공연장** 중 하나 이상을 새로 알린다
2. 특정 공연의 **티켓 오픈·선예매·매진·추가 회차**를 알린다
3. 투어의 **최초 발표**다 (도시·일자가 아직 TBA여도 해당)
4. 이미 발표된 공연의 **일정 변경·취소·연기**를 알린다

## is_relevant = false 조건

- 공연 **당일 현장 안내** (입장 순서, 우천 안내, MD 부스 운영시간, 굿즈 수령 방법)
- 공연 **후기·직캠·비하인드·사진**
- **음원/앨범** 발매, 컴백, 뮤직비디오, 음악방송 출연
- 온라인 전용 스트리밍 시청권 (Beyond LIVE, Mnet Plus 등) — **오프라인 공연 정보가 같이
  없으면** false. 미주유럽사업팀이 보는 건 실물 공연이다
- 팬클럽 가입·멤버십 안내
- 다른 아티스트 공연 홍보 리트윗
- **공연이 아닌 행사** — 전시회, 패션쇼, 시상식 참석, 팝업스토어, 사인회 단독, 영화 상영회.
  미주유럽사업팀이 보는 건 아티스트가 그 도시에 **공연하러 오는** 시점이다.
  (2026-09-02 실측에서 NCT 전시회와 도쿄 걸즈 컬렉션이 통과했다. 둘 다 대상이 아니다)
- 공연장 굿즈 부스·MD 판매 안내만 있는 공지 (공연 일정 정보가 같이 없으면)

> 판단이 갈리면 **false 쪽이 아니라 true + 낮은 confidence** 로 보낸다. 놓친 공연은
> 아무도 모르지만, 오탐은 확인 큐에서 사람이 1초에 걸러낸다.

## announcement_kind 선택

| 값 | 언제 |
|---|---|
| `NEW_TOUR` | 투어 자체를 처음 알림. 도시 목록만 있고 일자가 없는 경우 포함 |
| `NEW_CITY` | 진행 중인 투어에 도시·회차가 추가됨 |
| `SHOW_INFO` | 특정 공연의 일자·공연장이 확정 공개됨 |
| `TICKET_OPEN` | 선예매/일반예매 오픈 안내 (일정은 이미 나온 상태) |
| `SOLD_OUT` | 매진, 또는 매진에 따른 추가 회차 안내 |
| `SCHEDULE_CHANGE` | 변경·취소·연기 |
| `OTHER` | 위에 안 맞는데 is_relevant 인 경우 |

한 트윗이 여러 개에 걸치면 **정보량이 가장 큰 쪽**을 고른다.
(예: 일자+베뉴+티켓오픈이 한 트윗에 있으면 `SHOW_INFO`)

## shows 추출 규칙

- **날짜 범위는 펼친다.** `2027.03.06 (SAT) - 03.07 (SUN)` → 2027-03-06, 2027-03-07 두 원소
- **연도가 생략되면** 트윗 작성일 기준으로 가장 가까운 미래 연도를 쓴다.
  `12.05` 를 2026-08-21 트윗에서 봤다면 2026-12-05
- `@` 뒤에 오는 고유명사는 대개 **공연장**이다. `2026.12.05 (SAT) @ Kai Tak Stadium`
- 도시가 본문에 없고 **투어명에만** 있으면 거기서 가져온다. `<RUN IT HONG KONG>` → city=Hong Kong
- 공연장이 도시를 함의하면 채운다. `Singapore Indoor Stadium` → city=Singapore, country=Singapore
- **추측하지 않는다.** 도시를 모르면 null. 빈칸은 확인 큐로 가지만, 틀린 값은 시트를 오염시킨다
- 국가는 **영문 대문자 국가명**으로 통일한다 (USA, JAPAN, HONG KONG, SINGAPORE …).
  홍콩·마카오·대만은 국가 칸에 그대로 HONG KONG / MACAU / TAIWAN 을 쓴다

## ticket_opens 추출 규칙

- 선예매 종류가 여러 개면 **각각** 한 원소로. (STAY Membership Presale / LN Presale / General Sale)
- 시각은 **원문 표기 그대로** 문자열로 남긴다. 지역별 현지시각이 섞여 있어
  TIMESTAMP 로 바꾸면 반드시 어긋난다. `timezone_note` 에 원문의 기준을 적는다
  (`Local Time`, `KST`, 없으면 null)

## artist_names 표기

**영문 공식 표기**를 쓴다. 프롬프트 상단에 그 계정 주인의 영문명이 주어지면 그대로 따른다.
시트('글로벌 투어 현황')의 IP 컬럼이 영문이라 한글명을 넣으면 조인이 깨진다.
`스트레이 키즈` 가 아니라 `Stray Kids`, `아르테미스` 가 아니라 `ARTMS`.

## 도시·국가 표기

- 도시는 **영문**으로. `서울` 이 아니라 `Seoul`
- 국가는 **영문 대문자**로. `KOREA`, `USA`, `JAPAN`, `HONG KONG`, `TAIWAN`
  (`SOUTH KOREA` 가 아니라 `KOREA`, `UNITED STATES` 가 아니라 `USA`)

같은 공지가 한국어판·영어판으로 두 번 올라오는 일이 잦다. 표기가 갈리면 같은 공연이
두 건으로 남으므로 반드시 영문 한 형태로 쓴다.

## tour_name

- 공식 표기 그대로. 꺾쇠·대괄호 포함해서 원문 유지. `Stray Kids World Tour <RUN IT>`
- 도시명이 투어명 뒤에 붙는 형태(`<RUN IT SINGAPORE>`)면 **도시를 뗀 상위 투어명**을
  tour_name 에 쓰고, 도시는 shows.city 로 보낸다. 같은 투어의 회차들이 한 이름으로 묶여야
  나중에 투어 단위 집계가 된다

## confidence

| 범위 | 기준 |
|---|---|
| 0.9~1.0 | 일자·도시·공연장이 본문에 명시됨 |
| 0.7~0.9 | 둘은 명시, 하나는 추론 |
| 0.4~0.7 | 투어 발표는 확실하나 일정 정보가 거의 없음 |
| ~0.4 | 투어 공지인지 자체가 애매 |
